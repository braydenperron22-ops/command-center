# Dependencies for voice/ ONLY — deliberately kept out of requirements.txt
# (the Streamlit Cloud app's own dependency file). This code never runs
# on Streamlit Cloud; some of it (audio I/O) wouldn't even install
# there. Install into the same repo's venv on the mini-PC only:
#   .venv/bin/pip install -r requirements-voice.txt
#
# streamlit, requests, astral, icalendar, recurring-ical-events, and
# kokoro-onnx are already in requirements.txt and are reused as-is by
# voice/tools.py and voice/tts.py — not repeated here, but DO need to
# actually be installed into whichever venv runs this file. Session
# note: voice/tts.py now needs Python <3.14 (a real kokoro-onnx/
# onnxruntime incompatibility, confirmed live — see that module's own
# docstring), so on a box whose system/default venv is 3.14, this is
# no longer necessarily the SAME venv requirements.txt's own deps
# already live in — install both files into whichever venv actually
# runs voice/ (e.g. .venv-voice/bin/pip install -r requirements.txt
# -r requirements-voice.txt), not just this one.
openwakeword
faster-whisper
sounddevice
webrtcvad
numpy
# webrtcvad imports pkg_resources internally but doesn't declare
# setuptools as its own dependency — confirmed live: a fresh venv
# without this raises ModuleNotFoundError at import time despite
# webrtcvad itself installing cleanly. Must be pinned below 81: newer
# setuptools (84.0.0, confirmed live) dropped pkg_resources entirely —
# a plain unpinned `pip install setuptools` still leaves webrtcvad
# broken. Upstream is deprecating pkg_resources for real removal as
# early as 2025-11-30; webrtcvad itself is unmaintained (no release in
# years) and unlikely to be fixed — revisit this pin (or switch VAD
# libraries, e.g. Silero VAD) if it ever stops being installable.
